# Cloud File Manager & Storage System

A modern full-stack file storage application built with React, Node.js, and SQLite.

## Features
- Secure file upload and download
- AES-256 encryption at rest
- User authentication and role-based access control
- Responsive dashboard with search and tag filters

## Installation
```bash
git clone https://github.com/student/cloud-storage.git
cd cloud-storage
npm install
npm run dev
```

## Architecture
Built with microservices pattern using Express and SQLite.
